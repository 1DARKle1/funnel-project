## 4. Параметры события `utm_visit`

**Ссылка, по которой открывали сайт:**

```
https://ga4-analytics-lab-gamma.vercel.app/?utm_source=telegram&utm_medium=social&utm_campaign=ga4_lab
```

| Параметр | Значение в ссылке | Значение в GA4 |
|---|---|---|
| `utm_source` | telegram | в коде события берётся из адреса, на экране GA4 значение ещё не открыто |
| `utm_medium` | social | то же |
| `utm_campaign` | ga4_lab | то же |
| `landing_page` | - | в коде это `window.location.pathname`, для главной это `/` |

Кадр раскрытого `utm_visit` не приложен: это событие на экране GA4 в этом заходе не открылось.

В коде значения совпадают со ссылкой: `telegram`, `social`, `ga4_lab`. `landing_page` в ссылке нет, скрипт пишет путь страницы, для главной это `/`.
