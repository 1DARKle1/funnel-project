# Материалы занятий

Файлы, которые раздавались на занятиях: стенды, код для сайта, CSV,
шаблоны отчётов и чек-листы. Одна папка — одна тема. Конспекты лекций
лежат в папке [`lectures`](../lectures/README.md).

Файлы открываются на GitHub или в VS Code. Код для сайта из папок тем 6, 7
и 9 копируется в репозиторий своего сайта, в funnel-project его класть
не нужно.

| Папка | Тема | Что внутри |
|---|---|---|
| [`tema-01-vvodnaya`](tema-01-vvodnaya/) | Вводное занятие | ссылки на презентацию и конспект |
| [`tema-02-cifrovaya-voronka`](tema-02-cifrovaya-voronka/) | Цифровая воронка | конспект, исследовательское задание, стенд с формой |
| [`tema-03-utm-metki`](tema-03-utm-metki/) | UTM-метки | конспект, практика с кадрами, стенд со скрытыми полями |
| [`tema-04-google-analytics-4`](tema-04-google-analytics-4/) | Google Analytics 4 | ссылки на презентацию и конспект |
| [`tema-05-vercel-google-tag`](tema-05-vercel-google-tag/) | Свой сайт, Vercel и Google Tag | ссылка на шаблон сайта `ga4-analytics-lab` |
| [`tema-06-ga4-events`](tema-06-ga4-events/) | События и параметры GA4 | практика, сайт-пример, готовые файлы и `metrics.js` |
| [`tema-07-google-sheets-leads`](tema-07-google-sheets-leads/) | Контролируемая таблица заявок | практика, `Code.gs`, фрагмент формы, обработчики |
| [`tema-08-google-sheets-cleaning`](tema-08-google-sheets-cleaning/) | Google Таблицы: подготовка данных | CSV v1 и v2, формулы очистки |
| [`tema-09-instagram-manychat`](tema-09-instagram-manychat/) | Instagram → ManyChat → заявка | практика, тексты сообщений, проверки, `guide.html` |
| [`tema-10-ga4-explorations`](tema-10-ga4-explorations/) | GA4: отчёты и исследования | практика, шаблон анализа, чек-лист, карта полей |
| [`tema-10-2-datalens`](tema-10-2-datalens/) | DataLens | практика, спецификация дашборда, формулы, сверка |
| [`tema-11-hubspot-crm`](tema-11-hubspot-crm/) | HubSpot CRM | практика, CSV для импорта, карта свойств, сверка |

В файлах нет настоящих персональных данных: имена и адреса вымышлены,
почта на домене `example.com`. В своих проверках тоже используйте
только тестовые данные.
