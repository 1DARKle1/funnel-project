## Содержание лекции

GA4 принимает события с сайта и строит по ним отчёты: сколько людей пришло,
из какого источника, сколько дошло до заявки. Пример воронки из лекции:
320 посетителей → 48 открыли форму → 17 отправили заявку. Чтобы принимать
события, в GA4 создают структуру из трёх уровней.

| Уровень | Что это | Пример |
|---|---|---|
| Analytics Account | владелец данных: компания или проект; внутри может быть несколько ресурсов | ByteCamp |
| Property (ресурс) | набор данных одного продукта со своим часовым поясом и валютой; отчёты строятся на этом уровне | ByteCamp — сайт |
| Data Stream (поток) | источник событий: веб-сайт, приложение iOS или Android | Web: bytecamp.ru |

Google Account — личный вход в сервисы Google. Analytics Account создаётся
внутри него и может быть доступен нескольким людям.

### Настройка по шагам

1. **Analytics Account** — название владельца, настройки передачи данных.
2. **Property** — название, часовой пояс, валюта, сведения о бизнесе и цели.
   Часовой пояс определяет, к какому дню отчёт отнесёт событие: один и тот же
   момент 21:30 UTC в Москве уже следующий день.
3. **Web Data Stream** — протокол, домен сайта, название потока, переключатель
   **Enhanced measurement** (улучшенная статистика). Кнопка называется
   `Create stream` или `Create & continue`.
4. **Сведения о потоке** — здесь два идентификатора. Stream ID — числовой
   номер потока внутри ресурса. **Measurement ID** вида `G-XXXXXXXXXX` —
   идентификатор, который ставится в код сайта.

Enhanced measurement автоматически собирает часть событий: просмотры страниц,
прокрутку, исходящие клики, скачивания файлов, взаимодействие с формами.
Работает только после установки Google Tag на сайт. Событие `click` здесь
означает переход по ссылке на другой домен. События `generate_lead`,
`sign_up`, `purchase` требуют отдельной настройки.

После создания потока данных в GA4 ещё нет: на сайте не стоит код
с Measurement ID.
Установка тега — следующая тема.

## Термины

| Термин | Значение |
|---|---|
| Measurement ID | идентификатор веб-потока `G-…`; по нему событие попадает в нужный ресурс |
| Stream ID | числовой номер потока, в код сайта не ставится |
| Enhanced measurement | набор событий, которые GA4 собирает без дополнительного кода |
| Realtime | отчёт за последние 30 минут; в нём событие видно через несколько секунд |

## Что делали на занятии

1. Вошли на [analytics.google.com](https://analytics.google.com/).
2. Создали Analytics Account, Property и Web Data Stream для своего сайта.
3. Нашли и записали Measurement ID и Stream ID.
4. Разобрали, какие события собирает Enhanced measurement.
